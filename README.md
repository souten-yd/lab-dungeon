# 伝説の唐揚げダンジョン

100階の深淵から、黄金の唐揚げを取り戻す**ターン制グリッド・ローグライクRPG**。
ブラウザで動く単一ファイル製(HTML + Canvas)のローカルゲーム。
画像・音声をすべて ControlDeck の MCP(media-forge / sonic-forge)で生成している。

## 遊び方

- タイトルから「新しい冒険」でジョブ(5種)を選び、**町(地上)から冒険開始**。
- ダンジョンはマス目制。1行動(移動/攻撃/スキル/アイテム) = 1ターン。
- **待機中なら敵は絶対に動かない**。操作した直後に敵が行動する。
- 10階ごとに「セーブポイント」と「ワープゲート」が出現。
- 100階の「唐揚げ魔王」を倒すとクリア。
- 死亡時は**装備・金・アイテムをすべて失う**(レベルと解放した階は保持)。
- 地上(町)では買い物・売却・召喚獣の強化・全回復(宿屋)が可能。

## 操作 (ダンジョン)

| 動作 | キー | ターン |
| --- | --- | --- |
| 移動(8方向・1マス) | WASD / 矢印キー | 1 |
| 攻撃(向いているマス) | Z / J | 1 |
| スキル1 / 2 / 3 | X・K / C・L / V | 1 (MP消費) |
| アイテム使用 | 1 / 2 / 3 | 1 |
| 待機 | Space | 1 |
| 装備・アイテム整理 | Tab / I | **0** |
| ポーズ | P / Esc | 0 |

- 対角移動は両隣が床でないと不可(壁のすき間を縫えない)。
- 敵の赤い経路 = 次のターンに突進する兆し。横に避ける。
- 敵の弾は毎ターン1マス進む。そのマスを離れれば回避。
- 階段・宝箱は踏んだターンに発動。セーブポイントとゲートは自由。
- 町では 1/2/3 の薬使用が自由(ターン概念なし)。

タッチ操作も対応(ダンジョン: 左下8方向パッド+右上待/Bボタン、ジョイスティックスライドで1マス。メニュー: D-pad)。

## ジョブ

- **勇者**: 武器を使うほどその武器が覚醒(習熟ボーナス)。溜め斬り/突進/回復の光。
- **聖騎士**: 盾で受け流す重装の聖戦士。聖光斬/神聖の盾(次の敵ターン75%カット)/光の反撃。
- **賢者**: 魔法を撃つほど魔術書が完成し魔力が上がる。火球術(直線6マス)/氷結術(凍結)/雷撃。
- **召喚士**: 召喚獣(5種)が毎ターン自動戦闘し、実戦で最大10段階に進化。
- **無職**: 初期はゼロだが成長が誰より速い。万能器用/無双乱舞(2ターン移動2マス)/逆境の力。

## 実行方法

静的ファイルのみなので、ローカルHTTPサーバーで開く:

```bash
cd 唐揚げダンジョン
python3 -m http.server 8080
# ブラウザで http://localhost:8080 を開く
```

※ `file://` で直接開いても動くが、音声再生はサーバー経由が確実。

## 構成

- `index.html` — ゲーム本体(コードは1ファイル)
- `assets/` — 画像(スプライト・タイル・アイコン・背景)
  - `*_raw.png` — media-forge が生み出した元画像(1024px)
  - `*.png` — `tools/prepare_assets.py` でクロマキー除去・リサイズ済み
  - `*_walk.png` — 歩行アニメ2フレーム目(基本画像からの差分生成・31種)
- `audio/` — 音声(BGM 5 / SFX 16 / ボイス 4、ogg)
- `tools/prepare_assets.py` — 画像の前処理スクリプト
- `PLAN.md` — ターン制ローグライク化の実装計画(進捗チェック付き)

## アセット再生成

画像を再生成・再加工する場合:

```bash
# 1) media-forge で生成して assets/ に *_raw.png を配置
# 2) 前処理(クロマキー除去+リサイズ)を再実行
python3 tools/prepare_assets.py
```

- スプライト/アイコン: マゼンタ(255,0,255)背景を除去し、用途ごとにリサイズ。
- 背景/タイル/UI: 不透過のままリサイズ。
