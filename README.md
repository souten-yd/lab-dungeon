# 伝説の唐揚げダンジョン

100階の深淵から、黄金の唐揚げを取り戻す**ターン制グリッド・ローグライクRPG**。
ブラウザで動く単一ファイル製(HTML + Canvas)のローカルゲーム。
画像・音声をすべて ControlDeck の MCP(media-forge / sonic-forge)で生成している。

## 遊び方

- タイトルから「新しい冒険」でジョブ(5種)を選び、**町(地上)から冒険開始**。
- ダンジョンはマス目制。1行動(移動/攻撃/スキル/アイテム) = 1ターン。
- **待機中なら敵は絶対に動かない**。操作した直後に敵が行動する。
- 10階ごとに「セーブポイント」と「ワープゲート」が出現(100Fはセーブポイントのみ)。
- **ワープゲートは各10F帯の中ボスが守っている**。未討伐でZしても「○○ がワープゲートを塞いでいる…!」の表示のみ。**中ボス討伐で解放**され、以降「解放された階(10/20/…/90Fの討伐済み) ↔ 地上(町)」を自由に往復できる(解放は死亡・リロード後も保持)。
- **上り階段(緑矢印)**=降りてきた場所(入口)に常時設置。**そのマスで待機(Space/待機ボタン)**すると**一階上**へ戻れる(1Fのみ地上(町)へ)。踏むだけでは無反応・攻撃/スキル/アイテムでは上らない。中ボスに封じられることもない(撤退自由)。**上った先は必ずその階の降り階段の隣に到着する**(降りた先に降り階段がある整合)。
- **降り階段(下矢印)**=踏んでも**自動では降りない**。ターン消費→敵フェーズの後に**「降りる / 留まる」の選択**が出る(矢印で切替・**Z/Enter=降りる**・**X/Esc=留まる**)。留まればその場にとどまり、待機しても再び選択が出るだけ(離脱も自由)。100Fのみボス撃破後に直接clearへ(選択なし)・10F帯は中ボス討伐まで封鎖(従来通り)。
- 100階の「唐揚げ魔王」を倒すとクリア。
- 死亡時は**装備・金・アイテムをすべて失う**(レベルと解放した階は保持)。**HP/MPは全回復して地上(町)に戻る**(「倒れた…」画面上でおばあさんの声「死んでしまうとは情け無い。伝説のからあげへの道は遠いのぉ。」が流れる・Zで町へ)。
- **死亡後の初回ダンジョン入りのみ「死に戻り」テーマ曲**(女性ボーカル・日本語歌詞・約2分=何度死んでも諦めずに立ち上がる曲)が流れる(町入口・ワープゲート入口のどちらから入ってもOK)。その階中はループし、**次の入場以降は従来通りダンジョンBGM**。再死亡すればまた1回放れる。
- 地上(町)では買い物・売却・召喚獣の強化・全回復(宿屋)が可能。

## 中ボス(10F帯)

- 10/20/…/90F(100Fを除く)の**階段の隣に中ボス9体**が出現する。討伐しない限り階段は封じられる。
- 中ボスは**idle中は動かない・攻撃しない**。攻撃しても挑発扱い(最初の攻撃は無効)される。
- **隣接してZ(話す)** で挑発→台詞と咆哮とともに戦闘開始(BGMがその階の中ボス専用曲に)。専用曲9曲は唐揚げ王国への崇拝が深層ほど狂信的にエスカレート(10F=素朴な賛美歌→90F=終末の集団合唱)し、全曲に「**Ka-ra-a-ge!**」(唐揚げ)のヴォーカルフックを含む。
- HPが66%/33%を切ると男/女別の叫び、撃破時に死亡台詞。90F「ベリアル」は唐揚げ大魔王への祈りで最期を告げる。
- 撃破で:**階段解放**(以降、降り階段を踏むと「降りる/留まる」選択が出る) + **専用武器(9種・店では売らない)** + **その階のワープゲート解放**(元のゲートと町側のゲートの両方から「解放済み階 ↔ 地上(町)」を自由に行き来できる・ゲートは移動しない)。
- 討伐は**死亡しても保持**(セーブに記録)。再訪しても同じ階の中ボスは再出現しない。

## 操作 (ダンジョン)

| 動作 | キー | ターン |
| --- | --- | --- |
| 移動(8方向・1マス) | WASD / 矢印キー | 1 |
| 攻撃(向いているマス) | Z / J | 1 |
| スキル1 / 2 / 3 | X・K / C・L / V | 1 (MP消費) |
| アイテム使用 | 1 / 2 / 3 | 1 |
| 待機(上り階段マスでは=**一階上へ**) | Space | 1 |
| 装備・アイテム整理 | Tab / I | **0** |
| ポーズ | P / Esc | 0 |

- 対角移動は両隣が床でないと不可(壁のすき間を縫えない)。
- **対角への攻撃は可能**だが、**壁を挟む場合(両直交マスの片方が歩けない=対角移動と同じルール)は攻撃できない**=ぶつかった音が鳴って向き変更だけ(ターン消費・攻撃アニメなし)。壁や敵に移動でぶつかっても同様にぶつかった音が鳴る(向き変更のみ)。直線方向の壁への攻撃は従来どおりターンを消費する。
- **上下へ移動しても体の向き(左右)は変えない**(最後に左右へ動いた方向を維持)。攻撃・狙いは向いているマス(上下含む)へ。
- 移動中のスプライトサイズは静止時と常に一致(歩行フレームの内容を静止時サイズに正規化して描画)。
- 敵の赤い経路 = 次のターンに突進する兆し。横に避ける。
- 敵の弾は毎ターン1マス進む。そのマスを離れれば回避。
- 降り階段は踏んだターンに**「降りる/留まる」選択**が出る(=1ターン・自動降下なし)。宝箱は踏んだターンに発動(=1ターン)。上り階段は**待機(Space)で発動**。セーブポイントは自由。ゲートは**中ボス討伐後**にZで開く(1階入場1回)。
- 町では 1/2/3 の薬使用が自由(ターン概念なし)。

タッチ操作も対応(ダンジョン: 左下8方向パッド=移動(長押し=連続)・**左上スティック=方向転換(8方向・ターン消費なし・移動しない)**・右上待/Bボタン。メニュー: D-pad)。

## ジョブ

- **勇者**: 武器を使うほどその武器が覚醒(習熟ボーナス)。溜め斬り/突進/必殺「天翔り双月斬」(周囲2全敵atk×3.5+怯え)。
- **聖騎士**: 盾で受け流す重装の聖戦士。聖光斬/神聖の盾(次の敵ターン75%カット)/必殺「神聖裁き・光の審判」(周囲2 mag×3.0+自身HP15%治癒)。
- **賢者**: 魔法を撃つほど魔術書が完成し魔力が上がる。火球術(直線6マス)/氷結術(凍結)/必殺「星霜滅尽」(周囲3 mag×4.0+凍結)。
- **召喚士**: 召喚獣(5種)が毎ターン自動戦闘し、実戦で最大10段階に進化。召喚/獣の加護/必殺「百獣総出・獣神降臨」(獣が周囲2全敵mag×2.5総攻撃+獣強化)。
- **無職**: 初期はゼロだが成長が誰より速い。万能器用/無双乱舞(2ターン移動2マス)/必殺「無双・万象崩し」(周囲2 (atk+mag)×3.0)。
- **必殺技(3技能目)**: 高MP・長CDの"命の技能"。起動時に大エフェクト(ボイスは廃止)。

## 実行方法

静的ファイルのみなので、ローカルHTTPサーバーで開く:

```bash
cd 唐揚げダンジョン
python3 -m http.server 8080
# ブラウザで http://localhost:8080 を開く
```

※ `file://` で直接開いても動くが、音声再生はサーバー経由が確実。
※ **モバイル**: ブラウザの自動再生制限により、タイトルBGMは**画面を1回タップした後**に開始されます(タイトル画面にヒント表示あり)。
※ **横向き(スマホ/タブレット)**: 画面の縦横比に応じてゲームの表示幅が**動的に横へ拡張**され(16:9→最大約2.4:9)、横向きでも**黒帯なしで画面いっぱいに広がります**。画面を回転しても表示域・町・タッチUIが自動追従します。

## 構成

- `index.html` — ゲーム本体(コードは1ファイル)
- `assets/` — 画像(スプライト・タイル・アイコン・背景)
  - `*.png` — `tools/prepare_assets.py` でクロマキー除去・リサイズ済み
  - `*_walk.png` — 歩行アニメ2フレーム目(基本画像からの差分生成・66種=プレイヤー5+敵47(既存20+新規26+ボス1・mimicは宝箱を流用)+中ボス9+召喚獣5)
  - `*_raw.png` — media-forge の元画像(1024px)。**前処理後の中間ファイルで、容量削減のため常には保持しない**(再生成時は一時配置)
- `audio/` — 音声(81本: BGM 45 / SFX 35 / ボイス 1、ogg。BGM=ダンジョンテーマ別30(`bgm_dun_00〜09_a/b/c`=**実尺5分+**・英語ヴォーカル・シームレスループ・10F帯エモーションアーク: 冒険の意気揚々→辛さ→希望→大財宝目前→唐揚げ帝国への驚愕)+中ボス専用9(`bgm_mb_01〜09`=10F〜90F・約2分)+ボス+title/town/clear+フォールバック+**「死に戻り」テーマ曲`bgm_res`(女性ボーカル・日本語歌詞・約2分=死亡後の初回ダンジョン入りのみ)**。ボイス=老婆の死亡セリフ`voice_grandma_die`の1本のみ(2026-09-15の全ボイス廃止の後にT57で復活)
- `tools/prepare_assets.py` — 画像の前処理スクリプト
- `PLAN.md` — ターン制ローグライク化の実装計画(進捗チェック付き)

## アセット再生成

**新素材を追加**する場合(元画像が手元にある/新たに生成する場合):

```bash
# 1) media-forge で1024px画像を生成し assets/ に *_raw.png として配置
# 2) 前処理(クロマキー除去+リサイズ)を実行
python3 tools/prepare_assets.py
# 3) 中間ファイル *_raw.png を削除して容量を確保
rm assets/*_raw.png
```

- スプライト/アイコン: マゼンタ(255,0,255)背景を除去し、用途ごとにリサイズ。
- 背景/タイル/UI: 不透過のままリサイズ。
- 既存の処理済み`*.png`は最終成果物として保持。**元画像`*_raw.png`は削除済みのため、既存画像をRawから再導出はできません**(サイズ変更等は新素材として再生成してください)。
